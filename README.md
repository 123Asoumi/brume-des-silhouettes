# Brume des Silhouettes

Monde 3D en noir et blanc : un petit garçon en pagne traverse des plaines peuplées de titans aux masques africains, fuit les bêtes masquées et se cache derrière les rochers ou dans les cases.

Site statique (HTML + three.js via cdnjs). Aucun build : `index.html` est servi tel quel.

- `hero.json` / `hero.jpg` : personnage et ses animations (repos, marche, course)
- `nalesonko.mp3` : musique de fond — Ballaké Sissoko, *Nalesonko* (live)
